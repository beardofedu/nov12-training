# 6 · GitHub Universe 2026 highlights (7 minutes) and Q&A (5 minutes)

**Goal:** connect today's topics to what GitHub announced on October 28, 2026.

Sources: [GitHub Universe 2026: Evolving every layer of the stack](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/) and the [Universe recap](https://github.com/events/universe/recap). Re-check these links before presenting, because availability and pricing details can change.

## Theme

🗣️ "The headline was *completed work, not more code*: GitHub as an end-to-end delivery system where developers set direction and agents implement and verify."

## Copilot

| Announcement | One-line talking point |
| --- | --- |
| GitHub Copilot app | Agent-first app that takes work from issue to merge. |
| Copilot Fusion | Pick Standard, High, or Max effort; Copilot picks and combines models to balance quality, speed, and cost. |
| Copilot projects | Give Copilot a goal; it runs parallel sessions across repositories in one place. |
| Session continuity | One cloud agent session across the app, VS Code, CLI, and web. |
| Copilot automations | Scheduled or event-driven AI workflows that can propose improvements based on outcomes. |
| Copilot code review Max | A deeper review tier for high-risk changes. |
| Copilot connectors | Authenticate once to tools like Vercel, Cloudflare, and Sentry across Copilot surfaces. |
| Copilot with GitHub Enterprise | Enterprise customers can use Copilot features without a separate subscription and pay for AI credits used. |

## Platform

| Announcement | One-line talking point |
| --- | --- |
| Stacked pull requests | Break big changes into linked PRs; merge the stack in one click. |
| Issue artifacts | Attach plans and research to the issue that tracks the work. |
| `gh` `--attach` | Add images and video to issues and PRs from the CLI. |
| Infrastructure | Multi-region Azure migration and a new Git architecture for agent-scale traffic. |

## Security — tie back to sections 2–4

| Announcement | Ties back to |
| --- | --- |
| AI Scan | **CodeQL**: scans on demand, including languages CodeQL doesn't cover. |
| AI-powered push protection | **Security tab**: catches unstructured secrets such as passwords. |
| Reachability analysis | **Dependabot**: prioritize vulnerable functions your JavaScript actually calls. |
| Package firewall | **Supply chain**: blocks malicious npm packages before install. |
| Security canvas in the Copilot app | **Copilot**: explain and fix findings next to the code. |
